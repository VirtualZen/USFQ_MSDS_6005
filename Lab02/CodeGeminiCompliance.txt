from PIL import Image
import numpy as np
import matplotlib.pyplot as plt
from sklearn.decomposition import PCA

# 1. Cargar imagen y convertir a escala de grises
img = Image.open("IMG_9576.jpeg")
img_gray = img.convert("L")  
img_resized = img_gray.resize((512, 512), Image.LANCZOS)
img_array = np.array(img_resized, dtype=float)        

# 2. Aplicar PCA para compresión (Proyección en el espacio PCA)
pca_70 = PCA(0.70)
img_transformed_70 = pca_70.fit_transform(img_array)

pca_99 = PCA(0.99)
img_transformed_99 = pca_99.fit_transform(img_array)

# 3. Reconstrucción correcta desde el espacio comprimido
img_reconstructed_70 = pca_70.inverse_transform(img_transformed_70)
img_reconstructed_99 = pca_99.inverse_transform(img_transformed_99)

# 4. Visualización para comparación clara
plt.figure(figsize=(15, 5))
plt.subplot(1, 3, 1)
plt.title("Original (512x512)")
plt.imshow(img_array, cmap='gray')

plt.subplot(1, 3, 2)
plt.title(f"70% Varianza (k={pca_70.n_components_})")
plt.imshow(img_reconstructed_70, cmap='gray')

plt.subplot(1, 3, 3)
plt.title(f"99% Varianza (k={pca_99.n_components_})")
plt.imshow(img_reconstructed_99, cmap='gray')
plt.show()


Análisis 5.2: La cantidad de componentes afecta directamente la calidad de reconstrucción visual. Con una varianza del 99%, la imagen conserva casi todos sus detalles originales utilizando una fracción de las características iniciales. Al reducir la varianza al 70%, la compresión es extrema (usando un ‭$k$‬ muy pequeño); la imagen reconstruida pierde detalles finos y nitidez facial, mostrando un efecto de bloques o desenfoque. Esto evidencia el costo estructural de sacrificar componentes principales.
